# Automated Threat Detection System Using AWS

## Project Overview
This project implements an automated cloud security alerting system using AWS services. It detects security findings generated by Amazon GuardDuty and sends email notifications automatically through a serverless workflow.

## AWS Services Used
- **Amazon GuardDuty:** Generates security findings.
- **Amazon EventBridge:** Detects GuardDuty finding events and triggers the Lambda function.
- **AWS Lambda:** Processes security findings and initiates alert notifications.
- **Amazon SNS:** Delivers security alerts through email.
- **AWS IAM:** Manages permissions between AWS services.

## Architecture

Amazon GuardDuty → Amazon EventBridge → AWS Lambda → Amazon SNS → Email Notification

## How It Works
1. Amazon GuardDuty generates a security finding.
2. An Amazon EventBridge rule matches events with the source `aws.guardduty` and detail type `GuardDuty Finding`.
3. EventBridge invokes the `AutomatedThreatDetection` Lambda function.
4. The Lambda function processes the event and publishes a notification to the configured SNS topic.
5. Amazon SNS delivers the alert to the subscribed email address.

## Implementation
- Configured Amazon GuardDuty for security findings.
- Created an EventBridge rule to detect GuardDuty finding events.
- Configured the `AutomatedThreatDetection` Lambda function.
- Set up Amazon SNS for email notifications.
- Configured IAM permissions for publishing SNS messages.
- Tested the notification workflow using a sample GuardDuty finding.
